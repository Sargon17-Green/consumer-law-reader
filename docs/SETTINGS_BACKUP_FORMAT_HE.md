# גיבוי הגדרות משותף — schema 2

Android ו־iOS משתמשים באותו מאמת ובאותו פורמט ב־`web/mobile-core.js`. קובץ UTF-8 עד 1,000,000 בתים, ללא הצפנה או העלאה אוטומטית. בחירה בספק קבצים בענן היא פעולה של המשתמש. אין בקובץ תוכן משפטי, יומן שימוש, נתוני חשבון או מפתחות.

```json
{
  "format": "consumer-law-reader-settings",
  "schema": 2,
  "appVersion": "1.3.9-dev",
  "settings": {
    "law-reader-font": "24",
    "law-reader-align": "right",
    "law-a11y-m-no-motion": "1"
  }
}
```

`settings` הוא צילום מלא של ההגדרות שבתחום הגיבוי. מפתח חסר מוסר בשחזור; מפתחות מחוץ לתחום נשמרים. זו החלפה, ולכן מוצגת תצוגה מקדימה ונדרש אישור. הערכים כולם מחרוזות; שדות לא מוכרים וגרסאות schema לא נתמכות נדחים לפני כתיבה.

| מפתח | ערך תקין |
|---|---|
| `law-reader-font` | מספר שלם כמחרוזת, 16–28 |
| `law-reader-align` | `right` או `justify` |
| `law-reader-topics-v1` | מחרוזת JSON של מבנה נושאים schema 1; עד 900,000 בתים לתאימות לגיבויים ישנים |
| `law-a11y-m-contrast-dark`, `law-a11y-m-contrast-blue` | `0`/`1`; שני המצבים אינם יכולים להיות פעילים יחד |
| `law-a11y-m-underline`, `law-a11y-m-no-motion`, `law-a11y-m-gray`, `law-a11y-m-serif` | `0`/`1` |

נושאים: עד 500 נושאים אישיים ו־2,000 קישורים; כותרת לא ריקה עד 90 יחידות UTF-16; מזהים אישיים `u:` ואחריהם 1–100 אותיות ASCII, ספרות או מקפים. מאומתים ייחוד מזהים, קיום נושא אב, היעדר מעגלים, קיום יעדי DOM וקיום נושאי הבסיס. סדר מספרי סופי בתחום ±10,000,000. מטא־דאטה שנותרה בגרסאות ישנות אחרי מחיקת נושא אישי מתקבלת אם המזהה תקין; אינה יוצרת נושא חדש. הממשק החדש מגביל כתיבת מבנה נושאים חדש ל־450,000 בתים כדי להשאיר מקום לייצוא וליומן שחזור.

גיבוי iOS הישן `{ "format": "consumer-law-reader-settings-v1", "settings": {...} }` מתקבל עם אותו אימות ערכים ויעדים. שדות ישנים שאינם חלק מהעדפות המשתמש המוכרות נדחים, ולא משוחזרים באמצעות התאמת תחילית רחבה.

השחזור שומר תחילה צילום של הערכים הישנים ב־`law-settings-transaction-v1`. כשל בשריון מקום ליומן אינו משנה נתונים. כשל בכתיבה גורר rollback; אם התהליך הופסק, האתחול הבא משחזר מהיומן לפני קריאת ההעדפות. אין הבטחת עסקת אחסון חומרתית מעבר לערבויות `localStorage` ומערכת ההפעלה. הבדיקות מדמות כשלי quota והפסקת תהליך בין כתיבות.

ב־Android משתמשים ב־Storage Access Framework; אין הרשאת אחסון רחבה. קובץ ההכנה נמצא במטמון הפרטי ונמחק בסיום/ביטול; ב־Activity saved state נשמר דגל בלבד. ב־iOS הבחירה משתמשת ב־security-scoped URL, קריאה מוגבלת ברקע וקובץ ייצוא זמני עם הגנת קובץ; הוא מנוקה לאחר סגירת השיתוף. קבצים שהמשתמש שמר נשארים ביעד שבחר.

בדיקות: `tests/mobile_core_qa.js`, `tests/mobile_integration_qa.py`, `android/qa/.../ReaderInstrumentation.java`, `ios/ConsumerLawReaderTests/ReaderTests.swift`. המאמת המשותף נותן תאימות פורמט בין הפלטפורמות; כיסוי round-trip במנוע המשותף אינו לבדו הוכחה להעברת קובץ בין שני מכשירים פיזיים.
