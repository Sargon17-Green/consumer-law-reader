# חוק הגנת הצרכן — לנייד · גרסה 1.1.0

האפליקציה מבוססת על הארכיון שסופק בשיחה. היא כוללת את החוק, חקיקת המשנה, ההערות, ההגדרות, המקורות, הצעות החוק, הפרוטוקולים והיסטוריית הנוסחים שבמקור. נוסח משפטי חדש לא הובא ממקור חיצוני.

## שימוש

- סרגל תחתון: חיפוש, תוכן עניינים, ניווט לפי נושא, מקורות ועוד.
- ליד כותרות הסעיפים והתוספות: כפתורים נפרדים להיסטוריה, הצעות חוק, פרוטוקולים ומקורות. כפתור ללא חומר במקור אינו פעיל.
- מסך ״מקורות״: חיפוש לפי סעיף, כותרת או אסמכתה ומעבר בין סוגי המידע.
- כפתור ״פעולות״ בכותרת סעיף: העתקה, העתקת סעיף משנה, נוסחים קודמים ומקורות, כשאלה קיימים במקור.
- הקשה על הגדרה פותחת אותה בחלונית. הערות וחקיקת משנה נשארות ניתנות לפתיחה במקומן.
- ״עוד״: גודל טקסט, נגישות, הדפסה/שמירה כ־PDF, פרטי הקובץ.
- קישורים לפרסומים חיצוניים והתאריך המתעדכן בקובץ המקורי דורשים אינטרנט. הטקסט המצורף נמצא בתוך ה־APK.

## Android

קובץ ההתקנה הוא Consumer_Law_Mobile_1.1.0.apk. יש לפתוח אותו בטלפון ולהתקין. נדרשת Android 8 ומעלה, עם Android System WebView מעודכן. אם המערכת מבקשת, אפשר הרשאת התקנה למקור שממנו נפתח קובץ זה. אין צורך לבנות את הפרויקט כדי להשתמש באפליקציה.

שם החבילה: il.org.lawreader.consumer. גרסה 1.1.0, מספר בנייה 2.

## iPhone

גרסת הדפדפן מותאמת להתקנה במסך הבית דרך Safari. קישור והוראות מצורפים בקובץ INSTALL_HE.txt. זאת אפליקציית רשת מותקנת (PWA), ולא חבילת IPA או פרסום ב־App Store.

## תוכן הקוד

- original: קובצי המקור ללא שינוי, למעט קיצור דרך מקומי שאינו חלק מתוכן החוק.
- web: שכבת ההתאמה לנייד והאייקונים.
- android: מעטפת Android מקומית, העתקה ללוח, הדפסה ופתיחת מסמך Word מצורף.
- scripts: בנייה, אימות שימור התוכן וקליטת JSON של מקורות מוקלדים.
- contracts: החוזים המקוריים ופרטי המקור שלהם; חוזה source-first v002 הוא הקובע לתשתית החיפוש.
- typed-sources: מקום לקובצי JSON עתידיים והוראות קליטה בעברית; כרגע אין בו חומר מוקלד.
- tests: בדיקות מבנה וקליטה באמצעות חומר סינתטי שאינו נכלל בהתקנה.
- evidence: תוצאות אימות החתימה, פרטי החבילה והשוואת התוכן למקור.
- signing: מפתח החתימה והסיסמה שנוצרו בגרסה 1.0.0 ונשמרו לעדכון זה. יש לשמור אותם באופן פרטי; נדרשת אותה חתימה להתקנת עדכונים מעל גרסה זו.

## בנייה מחדש

סביבת Linux/WSL, Python 3.10 ומעלה ו־Java 17. מתוך תיקיית הפרויקט:

```sh
python3 scripts/fetch_tools.py
python3 scripts/build_android.py
python3 -m pip install -r requirements-qa.txt
python3 scripts/verify_release.py
python3 -m unittest discover -s tests -v
```

סקריפט ההורדה משתמש בכלי Android הרשמיים ובמהדר Eclipse ECJ. התוצאה נכתבת בתיקיית release. אפשר להשתמש בכלים קיימים באמצעות LAW_ANDROID_TOOLS.

לבניית גרסת הרשת בלבד:

```sh
python3 scripts/build_web.py
```

הקבצים המוכנים נוצרים בתיקיית dist; לשימוש ב־PWA יש להגישם משרת HTTPS. לא נכללים בקוד שרתים, חשבונות משתמשים או מסד נתונים.

## מקורות מוקלדים

הקלט הוא canonical-legislative-sources, גרסה 1, לפי 41 הטיפוסים בחוזה הקיים. יש להניח קובצי JSON בתיקיית typed-sources ולבנות מחדש. קלט שגוי או מזהים כפולים חוסמים את הבנייה. האפליקציה אינה מריצה קובצי Python של מקורות. פירוט מלא ב־typed-sources/README_HE.md.

האינדקס מאפשר חיפוש מדויק או מנורמל, סינון לפי הצעת חוק / ועדה / מליאה, הצגת הקשר, שיוכים, העתקת ציטוט ואסמכתה וקישור ישיר לכתובת מסמך המקור. הטקסט המוקלד נועד לאיתור; אין תצוגת תמליל המחליפה את מסמך המקור. קליטה נעשית בבנייה מחדש; אין ייבוא מתוך ממשק הטלפון בגרסה זו. לא נכלל חומר מוקלד אמיתי או חומר דוגמה בהתקנה.

## בדיקות ומגבלות אימות

אומתו חתימת ה־APK, שלמות הארכיון, התאמת הקבצים שבתוכו למקור, ושימור התוכן המשפטי והקישורים. בוצעו בדיקות בדפדפן ברוחבי 320, 375 ו־430 פיקסלים, לרבות חיפוש, ניווט, הגדרות, מקורות, נוסחים קודמים, העתקה ונגישות.

לא בוצעה התקנה על מכשיר Android או iPhone פיזי. לא אומתה פתיחת מסמך Word באפליקציה חיצונית או הדפסה במכשיר. זיהויים כפולים וקישור פנימי חסר שקיימים כבר במקור מתועדים ב־evidence/release-verification.json.

רכיב הנגישות הישן שתלוי בשירות חיצוני נשמר בקוד המקור אך אינו מופעל; התאמות התצוגה המקומיות זמינות בתפריט ״עוד״. תנאי השימוש, ייחוס המקור והערת ההגהה מתוך המסמך נשמרו באפליקציה.

בדיקות עדכון 1.1.0: 61 בדיקות שימור ואריזה; 9 בדיקות תשתית; בדיקות ממשק למקורות, היסטוריה ותוספות ברוחבי 320 ו־375 פיקסלים; בדיקה מבודדת לשלושת סוגי המקורות, ניקוד ורווחים, התאמה מדויקת, שיוכים, תווי HTML והעתקה. תעודת החתימה תואמת לגרסה 1.0.0. ממצאי בדיקות העדכון מתועדים בתיקיית evidence.
