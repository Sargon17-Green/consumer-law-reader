# חוק הגנת הצרכן — אתר קריאה ציבורי (GitHub Pages)

קישור קבוע: https://sargon17-green.github.io/consumer-law-reader/

הענף `gh-pages` מכיל אתר סטטי עצמאי. `index.html` טוען את `release.json`, מאחזר משאבים דחוסים ומאמת SHA-256 מול תוצר HTML המדויק לפני הצגתו. אין צורך בהתקנה או בהורדה ידנית.

גרסה נוכחית: **0.16** (2026-11-02). זהו תוצר אלפא, לא פרסום רשמי של רשות ממשלתית.

## עדכון עתידי

1. צור HTML גרסה חדשה מהממיר הדטרמיניסטי ובדוק אותו.
2. דחוס עם gzip, קודד base64, ופצל לנתיבים חדשים `assets/vX.Y/part-NN.txt` (ארבע שורות של 65,536 תווים בכל קובץ).
3. העלה את החלקים החדשים **לפני** שינוי המניפסט.
4. החלף ב-`release.json` את הגרסה, שמות החלקים, גדלים וגיבובי SHA-256 של HTML ושל gzip. זהו שינוי ההפעלה האטומי; `index.html` והקישור הציבורי נשארים קבועים.
5. בדוק את דף GitHub Pages דרך קישור ציבורי, כולל קישור עם #fragment לסעיף.

אין לפרסם מידע אישי או מידע פנימי באתר הציבורי. זכור שהעדפות המשתמש ב-localStorage קשורות למקור האתר ולכן יישמרו באותו URL בגרסאות הבאות.
