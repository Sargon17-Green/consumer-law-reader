# חוק הגנת הצרכן, התשמ"א–1981 — גרסת בטא 1.3.3

## מה הפרויקט מכיל

**היישום הראשי הוא אפליקציית Android לטלפון.** זו אינה הפצה של יישום מחשב נפרד.

- `releases/Consumer_Law_Reader_1.3.3_Beta_Android.apk` — קובץ ההתקנה המוכן לטלפון.
- `original/Consumer_Protection_Law.html` — **קובץ המקור המשפטי שכבר עובד בדפדפן במחשב**. הקובץ לא שונה במסגרת אריזה זו; כדי שתמונות, סמלים ונוסחאות יוצגו, יש לפתוח אותו כשהקבצים הנלווים מתוך `original/` נמצאים לצדו.
- `android/`, `web/`, `scripts/`, `tests/`, `contracts/` ו־`typed-sources/` — קוד ותשתיות ליצירת האפליקציה, בדיקות והמשך פיתוח.
- `NOTICE_HE.md`, `LICENSE`, `metadata/editorial_status.json` — הצהרות בעלות, רישוי ומועד בדיקת נוסח החוק.

## התקנה בטלפון Android

1. העבר לטלפון או הורד אליו את קובץ ה־APK שבתיקייה `releases/`.
2. פתח אותו בטלפון ואשר התקנה לפי ההנחיות של Android.
3. לשדרוג מהבטא הקודמת, נסה התקנה מעל הקיימת **מבלי להסירה**. לא בוצעה בדיקת שדרוג פיזית בסביבת הבנייה. אם מופיעה שגיאה, אל תסיר את הגרסה הקודמת לפני גיבוי הנתונים.

**אין להתקין קובצי ZIP.** כדי להתקין בטלפון צריך את קובץ ה־APK עצמו.

## פתיחת קובץ המקור במחשב (ללא התקנת אפליקציית מחשב)

במחשב פתח בדפדפן את `original/Consumer_Protection_Law.html` מתוך תיקייה שחולצה מה־ZIP, עם יתר הקבצים שבתיקיית `original/` לצדו. זהו **קובץ מקור לקריאה ולתחזוקה**, ולא קובץ התקנת Android. ממשק Android עשוי להיות שונה ממראה קובץ המקור בדפדפן.
